# IT Аварии

Android-приложение для срочного оповещения об авариях в IT-инфраструктуре.
Держит постоянное MQTTS-соединение с брокером AlertBackend и показывает громкое уведомление на каждый алерт, даже если приложение закрыто.

## Как устроено

- `AlertService` — foreground-служба, держит соединение. Android требует для неё постоянное уведомление в шторке.
- `MqttAlertClient` — MQTTS-клиент (Eclipse Paho): TLS с сертификатом брокера из `res/raw/broker.crt`, постоянная сессия и QoS 1. Если телефон был без связи, брокер доставит пропущенные алерты при переподключении.
- `Watchdog` — раз в 5 минут будит телефон и проверяет службу и соединение (во сне соединение может оборваться).
- `AlertStore` — история; одно и то же событие повторно не звенит.
- `Notifier` — громкие уведомления; критичные звучат как будильник и пробивают «Не беспокоить».
- События с одинаковым `id` (авария → восстановление) показываются одной карточкой с историей, уведомление звучит на каждое.

## Сервер

Параметры брокера — в `gradle.properties` (`mqtt.host`, `mqtt.port`, `mqtt.username`, `mqtt.password`, `mqtt.topic`).

- эмулятор: `mqtt.host=10.0.2.2` (компьютер, на котором запущен эмулятор);
- реальный телефон: IP компьютера в сети (он должен быть в сертификате — AlertBackend добавляет туда IP компьютера при создании).

Сертификат брокера: скопировать `AlertBackend/certs/broker.crt` в `app/src/main/res/raw/broker.crt`.

## Сборка

Откройте папку в Android Studio и нажмите ▶ Run, или:

```bash
./gradlew assembleRelease
```

Для релиза создайте ключ подписи и `keystore.properties` в корне проекта (файл в `.gitignore`):

```properties
storeFile=infra-alerts.jks
storePassword=...
keyAlias=infra-alerts
keyPassword=...
```

## Установка у коллег

1. Установить APK и открыть его.
2. Пройти мастер: уведомления, работа в фоне, «Не беспокоить».
3. На Xiaomi, Huawei, Honor, Samsung дополнительно включить «Автозапуск» и режим батареи «Без ограничений».

**Батарея без ограничений обязательна:** без неё Android может разрывать соединение во сне.
